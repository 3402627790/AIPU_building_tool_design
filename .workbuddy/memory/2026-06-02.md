# 2026-06-02 Work Log

## Added lowered IR save/load feature to MqBuilder
- Added `save_lowered_ir` and `load_lowered_ir` constants in `include/core/constants.h`
- Modified `src/builder/mqbuilder.cpp::build()`:
  - If `load_lowered_ir` is configured, parse the pre-lowered IR from .def file (skipping optimizer)
  - If `save_lowered_ir` is configured, serialize the graph after lowering to .def + .bin files
  - Uses existing `Graph::serialize()` and `Graph::parse()` methods
- Usage: set `BuilderConfig::set("save_lowered_ir", "path/to/graph.def")` to save, `BuilderConfig::set("load_lowered_ir", "path/to/graph.def")` to load
