## 讲解：ops API 是什么

用户问「什么是 ops api」，定位到本仓库的 `python/src/AIPUBuilder/ops/`（文档入口 `doc/ops.rst`，automodule 指向 `AIPUBuilder.ops`）。

结论要点（后续回答同类问题可直接复用）：
- ops API = AIPUBuilder 的 Python **建图 DSL**，230+ 算子，按域分 14 个模块（math/nn/array/reduction/activation/normalization/rnn/image/detection/control/special/logical/input/common）。
- 关键认知：**不做数值计算，只往 Graph 里加 Node**。返回 `Tensor` 句柄，含 shape/dtype/quantization，`out.op` 指向新 Node；数值要等 C++ Builder 编译 + 上板/仿真才有。
- 三层结构：Python 包装层（装饰器 + 类型归一化）→ pybind `_C._ops` → C++ `src/core/ops/*.cpp`（infer_shape、属性校验、真正建节点）。pybind 绑定源码不在本仓库（只有 modules/btrt 下有 PYBIND11_MODULE）。
- 标准装饰器链：`@eager_mode` → `@wrap_numpy_to_tensor` → `@check_rterrors`（含 infer_shape）→ `@check_input_op`（游离 Tensor 自动补 input/constant 节点）→ 函数体 `convert_*` 归一化 → `_ops.xxx()`。
- eager mode：`enable_eager_mode("opt"/"sim"/"npu"/"exe")`，本质给节点打 `_opt/_elf/_device/_exe` 属性后 `run_node(op)` 立即执行，用于调试。
- 真实用法范例见 `scripts/cost_model/create_dataset.py`（ops.input → ops.conv2d → 改 op.name / tensor.name → 喂给 profiler）。
